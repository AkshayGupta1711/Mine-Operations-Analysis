# ⛏️ Mine Operation Analysis

## 📌 Project Overview
This project analyzes mining operational data using **PostgreSQL, and Power BI** to evaluate production performance, equipment utilization, fuel consumption, maintenance activities, and safety metrics. The project demonstrates an end-to-end analytics workflow, from data storage and SQL analysis to interactive dashboard visualization, enabling data-driven decision-making in mining operations.

---

## 🎯 Objectives
- Store mining operational data in a PostgreSQL database.
- Analyze production and operational KPIs using SQL queries.
- Build an interactive Power BI dashboard.
- Generate insights to improve mine productivity and efficiency.

---

## 🛠️ Tech Stack
- **PostgreSQL**
- **Power BI**

## 🗄️ SQL Queries & Analysis
Used PostgreSQL to perform operational data analysis through SQL queries, including:
- Aggregate functions to calculate production, fuel consumption, and maintenance costs.
- `GROUP BY` and `ORDER BY` to analyze performance by equipment, pit, and shift.
- Filtering and sorting to identify key operational trends.
- KPI calculations to evaluate production achievement and equipment performance.
- SQL views to organize data for reporting and dashboard development.

---
## 📊 Dataset
- **Total Records:** 12,000
- **Domain:** Mining Operations
- **Key Attributes:**
  - Production Output
  - Equipment Utilization
  - Fuel Consumption
  - Maintenance Cost
  - Safety Incidents
  - Blasting Parameters
  - Operational Performance
